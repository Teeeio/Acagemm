# Historical Design Records

Files under this directory are historical plans and specifications. They record how earlier prototypes were designed and may reference deleted standalone CLI workflow files.

They are not current module contracts and must not be used as implementation authority. Current development authority is:

1. `AGENTS.md`
2. `docs/development/ARCHITECTURE.md`
3. the nearest module `README.md`
4. executable schemas, contracts, and tests

When historical text conflicts with production code or current module contracts, follow the current contracts and update them in the same change when behavior intentionally changes.
